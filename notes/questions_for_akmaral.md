# Questions for Akmaral

Ask before building, since each one changes the design:

1. Who is the audience, and where will they see this?
2. What is the single main message of the research?
3. Which figures from the paper matter most, and which can be dropped?
4. Is the data final, or will numbers still change?
5. Is anything in the data sensitive or embargoed, so it cannot go on a public page?
6. Does the page need to be in English only, or also Russian/Kazakh?
